# 第一篇博客

欢迎来到我的个人技术博客！这是我用 **VitePress** 搭建的第一篇文章，用来验证站点是否正常运行。

## 这是什么

这个博客基于 [VitePress](https://vitepress.dev/) 构建，托管在 **GitHub Pages** 上，访问地址：

> https://mmmaye.github.io/Blog/

## 我会写些什么

- Java 后端技术（JVM、并发、Spring 等）
- 中间件原理与实践（Redis、消息队列等）
- 系统设计与架构思考
- 学习方法与个人成长

## 一个代码示例

VitePress 内置 [Shiki](https://shiki.style/) 语法高亮，效果如下：

```java
public class HelloWorld {
    public static void main(String[] args) {
        // 一切伟大的旅程都从 Hello World 开始
        System.out.println("Hello, Blog!");
    }
}
```
